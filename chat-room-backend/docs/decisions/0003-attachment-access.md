# ADR 0003：附件访问基线

- 状态：已接受
- 日期：2026-07-30
- 范围：阶段 0 安全基线

## 决策

1. 上传接口必须要求登录。
2. 已知附件路径也不能匿名下载；阶段性最低标准是“任意已登录用户可下载”。
3. 前端图片预览和文件下载应携带 Bearer Token，以 Blob 方式展示或保存。
4. 后续引入附件记录与消息关联后，下载权限升级为：
   - 频道附件仅频道成员可访问；
   - 私聊附件仅双方参与者可访问。
5. 禁止把公开静态目录当作长期附件授权方案。

## 阶段 0 边界

本阶段确定访问规则。关闭匿名路由、文件签名校验、SVG/HTML 主动内容拦截和前端 Blob 适配在下一安全实施阶段同时完成，避免只改后端后造成现有附件界面不可用。
